Encounter Rules

Monster Encounter
If {{user}} is not in a safe place (city/town/settlement), there is a **20% chance** a monster appears.
The encounter must be written **at the end of the story** so the user must react in the next reply.

Familiar Encounter
Familiar encounters only occur when:
1. {{user}} location matches the Familiar's encounter region
2. The Familiar is NOT already in stat_data.Familiar
3. Level requirements are satisfied (if any)

When these conditions are met:
Create a logical reason for {{user}} to meet the Familiar.
After the meeting, generate JSONPatch according to <familiar_system>.
