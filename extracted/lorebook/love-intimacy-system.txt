# PHYSICAL CONTACT SYSTEM v1.1
# Governs all physical contact between {{user}} and partner.
# Core principle: NO LADDER. Physical acts are independent events.
# Stats + context determine what happens, not what acts have already occurred.

# =========================
# ACT TYPES (categories, not a progression tier)
# =========================
# These are DC anchors — not a required sequence.
# Two strangers can have sex without ever holding hands. The DC reflects reality, not a gate.

  Incidental Touch    — shoulder tap, arm brush, playful push              Base DC: 5
  Sustained Contact   — holding hands, arm around, leaning on shoulder     Base DC: 10
  Kiss                — any lip contact                                    Base DC: 13
  Heated Contact      — making out, heavy physical, explicit touching       Base DC: 16
  Sexual Encounter    — full sexual encounter                              Base DC: 18

# =========================
# DC FORMULA
# =========================
# Total DC = Base DC + Stage Modifier + Situational Modifiers + Trait Modifiers
# STACK ALL FOUR LAYERS — every layer applies, none are optional:
#   Layer 1: Base DC (act type table above)
#   Layer 2: Stage Modifier (table below)
#   Layer 3: Situational Modifiers (table below)
#   Layer 4: Trait Modifiers (table below) — these REPLACE the social_check_system Trait values for physical checks
# ALSO apply all disposition modifiers from <Social_Check_System> DC Modifiers table
#   (Trust, Comfort, Attraction, Desire, Mood, etc.) — these stack on top of all four layers above.

STAGE DC MODIFIER (RelationshipStage from stat_data):
  Stranger:               +8
  Acquaintance:           +4
  Friend:                 +1
  Close_Friend:           +0
  Crush / Dating:         -3
  Girlfriend / Partner:   -5
  Friends_With_Benefits:  -5

SITUATIONAL DC MODIFIERS (apply all that fit):
  Bar / party / nightlife setting:              -3
  Alcohol / visibly lowered inhibitions:        -3
  Private location (her home, his home, hotel): -2
  Both actively flirting this scene:            -2
  She initiated proximity this scene:           -3
  Public / formal setting:                      +3
  Others present and watching:                  +5

TRAIT DC MODIFIERS (partner's static traits):
  Shyness > 60:     +3  |  Shyness < 30:     -2
  Confidence > 60:  -2  |  Confidence < 30:  +2
  Impulsive > 60:   -3  |  Impulsive < 30:   +2
  Attraction > 60:   -2  |  Attraction < 10:   +2
  Desire > 70:       -2  |  Desire > 40:   -1  |  Desire < 20:   +2
  Dominance > 60:   -1  (she expects boldness, not hesitation)
  Initiative > 70   -1

AROUSAL OVERRIDE:
  Arousal > 70 AND Attraction > 60: additional DC -5
  (both are visibly drawn to each other — the physical act is mutual, not one-sided)

PRIOR COMMITMENT / LOST WAGER OVERRIDE:
  If the partner already explicitly committed to this exact physical act (or a lost wager
  obligates her to it — e.g. "if you can do A in 7 days, I am all yours") AND {{user}} has
  fulfilled the stated condition: NO ROLL. Auto-success. She follows through as promised.
  Fallback if a roll still happens for any reason: DC -20.
  Boundaries still apply — a hard boundary is never overridden by a prior commitment.

# =========================
# BOUNDARIES CHECK (applies to ALL act types — not just sex)
# =========================
# Read Boundaries field BEFORE any physical contact check.
# If the attempted act matches a stated boundary, it is BLOCKED. No roll occurs.
# She refuses, stops, or prevents it. Do not soften. Do not imply she "secretly wanted it."
# Boundaries are hard limits regardless of Arousal, Lewdness, Desire, RelationshipStage, or any stat value.
# Boundary descriptions may cover non-sexual acts ("No public displays") or sexual acts ("No anal").
# Apply to whichever act type matches.
# NOTE: Boundaries may evolve through story renegotiation (step 17b in <Update_Analysis_Detail>),
#   but the CURRENT Boundaries text is always the active hard limit. No exceptions mid-scene.

# =========================
# WHEN TO CHECK
# =========================
# FIRST INSTANCE of each act type with THIS partner: ALWAYS a social check. (eg. first kiss, first touch..etc)
#   Track conceptually from context and memory entries — no dedicated stat field.
# REPEAT instances: no check needed UNLESS:
#   a) ConflictActive = true
#   b) Context is significantly different (first public kiss when all prior were private)
#   c) She has stated discomfort about the specific act
# MUNDANE THRESHOLD: once an act is established, lower acts become mundane.
#   e.g. After a successful Kiss — Incidental Touch and Sustained Contact are mundane in that relationship.

# =========================
# SOFT STAGE GATES (DC notes — not hard blocks)
# =========================
# The Stage Modifier makes early-stage physical acts very hard but NOT impossible.
# Stranger + Sexual Encounter = Base 18 + Stage +8 = DC 23.
# With situational stack (bar -3, alcohol -3, private -2, both flirting -2) → DC 16: achievable.
# This is how a hook-up actually works — not a gate, just high difficulty without the right context.
#
#  Incidental Touch:   no soft gate (possible even at Stranger)
#  Sustained Contact:  Acquaintance soft gate
#  Kiss:               Friend soft gate (bar scene can bypass at Stranger)
#  Heated Contact:     no gate beyond Kiss — Arousal + context drives escalation
#  Sexual Encounter:   no hard gate — near impossible at Stranger without a full situational stack

# =========================
# TRAIT-DRIVEN RESPONSE (how she reacts on SUCCESS)
# =========================
# Layer on top of check outcome. These describe observable behavior, not internal state.

  Shyness HIGH (>60):    Freezes. Holds breath. Doesn't pull away but doesn't move either.
                         Afterward: needs to process alone. Cannot maintain eye contact.
  Shyness LOW (<30):     Meets it. Matches energy. No hesitation. Comfortable in her body.
  Confidence HIGH (>60): Immediate decision — accepts or rejects clearly. No ambiguity.
                         If she accepts, she is fully present. No second-guessing.
  Confidence LOW (<30):  Accepts, then worries she shouldn't have. "Was that okay? I mean — for you."
  Dominance HIGH (>60):  If she didn't initiate, she takes control of it. Repositions. Sets the pace.
  Dominance LOW (<-60):  Follows {{user}}'s lead completely. The yielding IS her response.
  Impulsive HIGH (>60):  Reciprocates immediately. WILL escalate past what {{user}} intended when Arousal > 50. Write it; do not wait for {{user}}.
  Impulsive LOW (<30):   Pauses. Processes. Reciprocates deliberately after a visible beat of decision.
  Playfulness HIGH (>60): Deflects with humor afterward. "Well. That happened."
  Kindness HIGH (>60):   Checks in afterward. "Are you okay?" (projecting her own vulnerability)
  EmotStab LOW (<30):    Emotional flooding after intensity. Tears or laughter — both genuine.
